Research Context

研究の背景と価値

なぜ今、このシステムを作るのか

🏭
社会的背景
高齢化・人手不足が加速し、工場・病院・家庭で自律ロボットのニーズが急増。単純な移動だけでなく「判断できるロボット」が求められている。
🧠
技術的挑戦
記憶・文脈理解・マルチモーダル認識を統合した AI OS はまだ黎明期。Perception→Memory→Agent→Skill→Robot という神経系アーキテクチャの実装。
🎯
実現したいこと
音声指示・過去記憶・視覚情報を統合し、屋外〜屋内をシームレスに移動して物体操作できる「実用レベル」のロボット神経系を構築する。

① 単発物理操作（Harness なし）
LLM + センサー + ROS2 の直接パイプライン。Harness システムなしで基礎能力を実証。移動・アーム操作・複合の3例。
【移動】 🗣️ 音声指示 → LLM 解釈 → 🗺️ SLAM+Nav2 走行 → 📝 走行ログ → ✅
【アーム】 🗣️「3階を押して」→ YOLO/VLM 認識 → IK → 🦾 押下 → ✅
【複合】 🗣️ 複合指示 → LLM 分解 → 移動 + アーム操作 → ✅
SLAMNav2LLMWhisperSOARM101YOLO/VLM
② Agent + Memory + Skill API
単発操作能力を内包した上で、Skill API・Planner Agent・RAG Memory が加わる。文脈指示・マルチステップ操作・Cron 巡回の3例。
【文脈移動】 🗣️ 文脈指示 → 🧠 RAG Memory 検索 → Planner Agent → Skill: goto() → 📝 Memory 更新
【マルチステップ】 🗣️「CAT を並べて」→ Planner 計画 → Skill: pick()×3 → 配置 → ✅
【巡回】 ⏰ Cron → Ops Agent → Skill: patrol() → Heartbeat 正常

③ 自律異常対処 + 人とのインタラクション
前 Level の全能力を内包した上で、Self-Check・Multi-Agent・Human-in-the-loop を追加。移動中の障害対処と精密操作の失敗回復を実証。
【移動異常】 🚶 巡回中 → Self-Check: ドアが閉 → Multi-Agent 判断 → 別経路再計画 or 👤 人に開錠を依頼
【操作回復】 👁️ 精密認識 → 🦾 操作中 → 失敗検知 → Self-Progress 補正 → 不確実時 🔊「確認してください」→ ✅
                    → 📝 Memory に成否・補正量記録
