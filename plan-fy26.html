Research Context

研究の背景と価値

なぜ今、このシステムを作るのか

🏭
社会的背景
高齢化・人手不足が加速し、工場・病院・家庭で自律ロボットのニーズが急増。単純な移動だけでなく「判断できるロボット」が求められている。
🧠
技術的挑戦
記憶・文脈理解・マルチモーダル認識を統合した AI OS はまだ黎明期。Perception→Memory→Agent→Skill→Robot という神経系アーキテクチャの実装。
🎯
実現したいこと
音声指示・過去記憶・視覚情報を統合し、屋外〜屋内をシームレスに移動して物体操作できる「実用レベル」のロボット神経系を構築する。

デモシナリオを選択
⑥ 屋外・屋内 × 精密操作 × 安全 × 記憶 — 統合最終デモ ⭐（C-L3）
全要素統合。屋外・屋内シームレス走行＋Safety Agent＋記憶システム＋精密フィードバック操作が連携する集大成デモ。
🗣️ 複合指示
 ↓ 🧠 Memory 参照（RAG + Vector DB）
 ↓ 🌳 屋外走行（GNSS+SLAM）→ 🏢 屋内移動（Nav2）
 ↓ ⚠️ Safety Agent 監視 → 👁️ VLM 認識
 ↓ 🦾 精密操作（Closed-loop）→ 📝 Memory 更新・報告
GNSS+SLAMSafety AgentRAG MemorySOARM101Closed-loopWhisper
① SLAM 自律移動 & エレベーターボタン押下（A-L1 / B-L1）
音声指令で SLAM 自律移動＋走行ログ記録（A-L1）と、指示によるエレベーターボタン押下（B-L1）を実証する最初の実用デモ群。
【A-L1】 🗣️ 音声指示 → LLM 解釈 → 🗺️ SLAM+Nav2 走行 → 📝 走行ログ記録 → ✅ 到達
【B-L1】 🗣️「3階を押して」→ YOLO/VLM 認識 → 📐 IK → 🦾 押下 → ✅
ORB-SLAM3Nav2LLMWhisperSOARM101YOLO
② 移動 & 操作 複合デモ（C-L1）
「〇〇に移動してボタンを押して」を1つの音声指示で実行。LLM がタスク分解し、SLAM移動とアーム操作を連続実行。
🗣️ 音声指示 → 🤖 LLM 分解（移動 + アーム）
 ↓ 🗺️ SLAM+Nav2 移動 → 📝 走行ログ
 ↓ 👁️ ターゲット認識 → 🦾 アーム操作 → ✅
Nav2SLAMSOARM101LLM PlannerWhisper
③ 記憶システム活用 & 文字スペリング（A-L2 / B-L2）
走行ログを Vector DB に蓄積し文脈ある移動指示に対応（A-L2）。物品名から文字ブロックをスペルアウト（B-L2）。
【A-L2】 🗣️ 文脈指示 → 🧠 RAG 記憶検索 → 📍 位置推定 → 🗺️ 移動 → 📝 Memory 更新
【B-L2】 🗣️ 物品名 → LLM 計画 → 👁️ OCR+YOLO → 🦾 把持×N → ✅
RAGEpisodic MemoryOCRYOLOSLAM
④ 記憶 × 自律デリバリー（C-L2）
「前に置いてあった〇〇を取ってきて」など Episodic Memory を参照した文脈指示に対応。移動→把持→搬送→配置を一貫実行。
🗣️ 文脈指示 → 🧠 Memory 検索（RAG+Vector DB）
 ↓ 🗺️ SLAM+Nav2 移動 → 👁️ YOLO
 ↓ 🦾 把持・搬送・配置 → 🧠 Memory 更新 → ✅

⑤ 屋外・屋内シームレス走行 & 精密操作（A-L3 / B-L3）
GNSS+SLAM で屋外→屋内を安定走行し Safety Agent が自律判断（A-L3）。プラグ挿入など視覚フィードバック精密操作（B-L3）。
【A-L3】 🌳 屋外（GNSS+SLAM）→ 🏢 屋内（Nav2）→ ⚠️ Safety Agent → 🧠 記憶参照
【B-L3】 👁️ 挿入口認識 → 📐 精密 IK → 🔄 視覚 Feedback ループ → ✅
