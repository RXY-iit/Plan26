Level Structure

Level 1–3 の包含関係

Level は線形の「段階」ではなく「包含」関係 — 上位 Level は下位 Level の全能力を内包し、さらに高階 Harness 機能を追加する

Level 3 — 高階 Harness
Level 2 — Harness 中層
Level 1 — 基盤
L1 基盤 — 単発の物理操作 Ph 0–1

LLM + センサー + ROS2 の直接パイプライン。Harnessシステム不使用。音声指示 → 認識 → 単発動作実行。

SLAM LLM基盤 IK/FK MCP Isaac Sim基盤
L2 Harness中層 — 複数手順の自律構成・実行 Ph 2–5

L1 を内包した上で Skill API・Planner Agent・Memory・Cron・Heartbeat が加わる。目標だけ与えれば手順を自律構成して実行。

Tool Use Agent Cron Heartbeat Memory VLA RL Isaac Lab
L3 高階 Harness — 自己診断・協調・人との対話 Ph 6–8

L1+L2 を内包した上で Self-Check・Multi-Agent・User-Interactive が加わる。異常を自律対処し、不確実なときは人に確認を求める。
