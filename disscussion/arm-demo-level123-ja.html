マニピュレーション Level 1-3 — Harness 包含構造

Level は「段階」ではなく包含関係 — L3 ⊃ L2 ⊃ L1。
L1: Harness なしの単発物理操作 ／ L2: L1 を内包し Skill API + Agent を追加 ／
L3: L1+L2 を内包し Self-Check・Human-in-the-loop など高階 Harness を追加する。
LLM・視覚認識・動作計画・Harness システムを組み合わせ、Physical AI 的マニピュレーションを検証する。

Level 1–3 の包含関係図
Level 3 — 高階 Harness
Level 2 — Harness 中層
Level 1 — 基盤
L1 基盤 — 単発の物理操作 Ph 0–2

LLM + 視覚認識 + ROS2 の直接パイプライン。Harness システムを使わず、音声指示から単発の物理操作を実行する最小構成。

L2 Harness 中層 — Skill API + Agent Ph 3–5

L1 を内包した上で Skill API・Planner Agent・Memory が加わる。目標から手順を自律構成し、複数ステップの操作を連続実行する。

L3 高階 Harness — Self-Check + Human Ph 7–8

L1+L2 を内包した上で Self-Check・状況理解・Human-in-the-loop を追加。不確実な状況でも適応的に操作し、必要時は人と協調する。

L1
音声指令による単発操作実行
例：エレベーターボタン押下 / 設備スタートボタン / スイッチ操作
● planned · Ph 0–2 · Harness なし
💡 望ましいこと（Why）

研究室・工場・施設内には、「ボタンを押す」「スイッチを入れる」といった 単純だが人手依存の操作が多く残っている。

既存設備とシステム連携しようとすると改修コストが高く、 従来の自動化では見合わないことが多い。

つまり、"人がその場で行っている簡単な物理操作を、 設備改造なしで代替したい"というニーズがある。

→
🎯 このLevelで実証すること（What）

「3階のボタンを押して」のような自然言語指示を受け、 対象を視覚的に認識し、位置を推定し、アームで正確に押下する。

これにより、言語理解 → 対象認識 → 物理操作 の最小パイプラインを実証する。

環境改造なし、固定座標スクリプトなしで動作することがポイントである。

⚠ 解決したい痛点
✕設備側を改造しないと自動化できない
✕座標固定スクリプトでは環境変化に弱い
✕人の指示をそのままロボット動作に変換できない
✨ このデモの価値

「環境改造なしの低コスト自動化」の可能性を示す。

ボタン押下自体が重要なのではなく、 人の言葉で指示された単発作業を、 視覚を使ってその場で実行できることが重要である。

実装例
1-A
指令ベースの各種パネル操作
仕様の異なるパネルを視覚認識で汎用的に操作する
シナリオ

「エレベーターの3階ボタンを押して」「機器のスタートを押して」「照明を消して」といった 音声コマンドを受け、その場にあるパネルを視覚的に認識して目標ボタンを特定・押下する。

各パネルの仕様（ボタン配置・サイズ・ラベル・素材）はそれぞれ異なるため、 固定座標スクリプトは使えず、VLM + LLM による汎用認識が必要となる。

🗣️ 音声「3階ボタン押して」 › 🤖 LLM: target="3", panel="elevator" › 📸 カメラでパネル全体撮影 › 👁️ VLM でボタン一覧 + ラベル認識 › 📐 "3" ボタンの Depth 推定 → IK › 🦾 押下 → LED点灯確認
技術的なポイント
▸ パネル多様性への対応：エレベーター（数字配列）/ 機器パネル（機能ラベル）/ 壁スイッチ（ON/OFF）を統一パイプラインで処理。VLM がパネル種別を自動判定し、LLM がコマンドと対応付ける
▸ Depth 精度：RealSense の点群 or ステレオ深度で押下点の Z 距離を推定。ボタンの出っ張り・埋め込みによる ±5 mm 誤差を IK で吸収
▸ 押下確認：力センサー（電流変化）または映像（LED/ランプ点灯・表示変化）で成否を判定し、フィードバック
対象パネル例
エレベーターパネル（数字配列） 機器操作パネル（スタート/ストップ） 壁面照明スイッチ 設備緊急停止ボタン
1-B
音声指示によるねじの片付け
散らばったねじを認識し、指示された回収先へ順次ピック＆プレースする
シナリオ

「机の上のねじを片付けて」「こぼれたねじをトレイに戻して」といった 音声コマンドを受け、作業台上に散らばったねじを検出し、1本ずつ把持して回収箱や部品トレイへ移載する。

小さく似た形状の物体を見分けながら、散在した複数個を順番に回収することがポイントで、 単発のピックだけでなく「軽い片付け作業」まで自動化できることを示せる。

🗣️ 音声「ねじを片付けて」 › 🎙️ Whisper で文字起こし › 🤖 LLM: object="screw", action="tidy" › 👁️ YOLO/VLM でねじ候補抽出 › 📐 Depth + IK で把持位置決定 › 🦾 ピック → トレイへ移載 → 残数確認
技術的なポイント
▸ 音声から作業意図を抽出：Whisper で音声をテキスト化し、LLM が「対象=ねじ」「動作=回収」「回収先=トレイ」のようにタスクへ変換。自然な片付け指示をそのまま扱える
▸ 小物認識と選別：ねじ・ワッシャ・ナットのような似た部品が混在していても、YOLO/VLM でねじだけを抽出。頭部形状や長さ差を使って誤把持を減らす
▸ 連続回収の安定化：小さな金属部品は滑りやすいため、把持点を毎回再計算し、持ち上げ高さの変化やトレイ投入後の見え方で1本ずつ回収完了を確認する
対象部品・回収先例
ねじ・ビス類 部品トレイ 小物回収箱 作業台上の散在部品

💡 望ましいこと（Why）

実際の現場では、ロボットに求められるのは 「1回動くこと」ではなく、目的に応じて複数ステップを継続実行することである。

指定順に物を並べる・必要な部品を集めて配置する・ラベルに基づいて選別するといった作業は、 ロボットにとっては認識・記憶・順序計画・反復操作が必要になる。

「1回ごとに人が次の指示を出す」ことへの依存を減らしたい。

→
🎯 このLevelで実証すること（What）

「CAT を並べて」「APPLE を作って」といった指示を受け、 対応する文字ブロックを認識し、順序を計画し、 複数回の把持・配置を継続して行う。

これにより、単発操作ではなく、目的に対して自律的に 手順を展開する能力を示す。

⚠ 解決したい痛点
✕既存ロボットは固定シーケンスに依存しやすい
✕目標が変わるたびに人がプログラムし直す必要がある
✕複数ステップ作業を柔軟に扱えない
✨ このデモの価値

「動作の自動化」ではなく「タスクの自動化」に進む点にある。

人が逐一「次はこれ」と教えなくても、 目標だけ与えればロボットが内部で手順を構成して実行できることを示す。

2-A
手順書通りに積み木を積む
ステップ記述を読み、色・サイズで認識して順序通りに積み上げる
シナリオ

「赤→青→黄の順に積んで」「大きい順に3つ重ねて」などの指示を受け、 散乱した積み木をカメラで認識し、LLM が手順を解釈して 正しい順序で把持・配置を繰り返す。 積み上げ中はスタックの傾き・ずれをカメラで監視し、 補正しながら次のブロックを置く。

📋 手順指示を LLM 解釈 › 👁️ YOLO: 色・サイズ認識 › 📋 積み順を計画リストに変換 › 🔁 [把持 → 配置 → 確認] × N回 › ✅ 完成判定
技術的なポイント
▸ ステップ管理：LLM が生成した手順リストを状態機械として管理。各ステップ完了後に画像確認し、次ステップへ遷移
▸ 安定把持・配置：ブロック上面の中心を Depth で取得し、置く際の高さオフセットを積み上げ段数から動的に計算
▸ 失敗リカバリー：ブロックが崩れた場合、カメラ確認後にリスト先頭から再試行
2-B
認識した物体で文字を並べる
文字ブロックを OCR で読み取り、目標の単語になるよう配置する
シナリオ

「ROS と並べて」「CAT を作って」と指示すると、 卓上に散らばった文字ラベル付きブロックをカメラで認識し、 必要な文字を選別・収集し、指定した単語の順に左から並べる。 ブロックには英字、数字、記号が混在しており、 OCR + VLM で文字を読み取ってから選択判断する。

🗣️「CAT を作って」 › 🤖 LLM: ['C','A','T'] に分解 › 📸 全ブロックをスキャン › 👁️ OCR: 各ブロック文字 + 座標 › 📋 配置計画（左→右順） › 🦾 C→A→T 順に把持・配置
技術的なポイント
▸ 文字認識精度：ブロックの傾き・照明変化に対して OCR が頑健に機能するよう、複数角度から再撮影 or VLM で補完
▸ 欠字対応：必要な文字ブロックが見つからない場合、LLM が「C が見つかりません」とフィードバックし、人に追加依頼
▸ 配置精度：揃って見えるよう、指定した仮想グリッド座標（列 × 行）に基づいて IK を計算
Level 3
L3
高階 Harness（L1+L2 内包）— Self-Check + Human-in-the-loop + 精密操作
例：Closed-loop 精密操作・3回失敗 → TTS 報告・人補助 → 再試行・Memory 成否記録
◌ future · Ph 7–8 · L1+L2 内包
💡 望ましいこと（Why）

現実の高価値作業の多くが、ミリ単位のズレで失敗する精密操作である。

プラグ・USB挿入、コネクタ接続、穴位置合わせ、接触を伴う精密作業は、 単純な位置決めだけでは不十分で、 誤差・たわみ・視点変化・個体差が常に存在する。

望まれているのは"一回で正確に動くロボット"ではなく、 "ずれても自分で修正できるロボット"である。

→
🎯 このLevelで実証すること（What）

対象を認識して初期位置合わせを行うだけでなく、 作業中の映像や接触状態を使ってリアルタイムに補正しながら挿入を完了する。

これにより、open-loop な再生動作ではなく、 閉ループで成功に到達する能力を示す。

⚠ 解決したい痛点
✕高精度な事前調整がないと作業が成立しない
✕少しの誤差で失敗する
✕環境変化に弱く、実運用で安定しない
✨ このデモの価値

不確実環境でも成功まで持っていけるロボット操作を示す。

「プラグを挿せた」ことそのものではなく、 認識・接触・補正を組み合わせて、 失敗しやすい作業をやり切れることが、実環境導入に向けた大きな一歩となる。

実装例
3-A
差し込みプレートへの挿入
穴位置を視覚認識し、接触フィードバックで誘導しながら挿入完了する
シナリオ

複数の穴が格子状に配置された差し込みプレート（ペグボード）に対し、 「左上の穴に赤いピンを挿して」などの指示に従い、 目標穴を視覚認識して接近し、接触を感知しながら挿入を完了する。 穴径とピン径の余裕は ±1 mm 程度で、正確な軸合わせが必要。

🗣️ 挿入位置を指定 › 👁️ VLM: 穴位置 + 深度推定 › 📐 初期 IK: 穴上方 30 mm へ › 🦾 垂直降下アプローチ › 🔄 接触検知 → 軸ずれ補正ループ › ✅ 挿入完了（電流 / 映像）
技術的なポイント
▸ 穴検出精度：カメラ画像でエッジ検出 + Depth で穴中心の 3D 座標を ±0.5 mm 精度で取得
▸ 挿入時の補正：ピンがプレート面に接触した後、電流上昇パターンと視覚の位置ずれから「どの方向にずれているか」を推定し、微小移動で補正
▸ 挿入完了判定：指定深度まで到達（電流正常 + 位置センサ）で完了とし、失敗時は引き抜いて再試行
難易度を上げる発展
複数穴への連続挿入 パターン指定（図形・文字） USB / 電源プラグへの拡張
3-B
工具を使った作業
ドライバー・レンチを把持し、適切な力・方向で対象に作用させる
シナリオ

作業台に置かれたドライバーを把持し、 「このネジを締めて」と指示されたネジ頭に位置合わせし、 垂直に押し付けながら回転動作でネジを締める。 ネジ頭の十字溝にビットが正確に嵌合しないと空転するため、 視覚 + 接触 + トルクの三重フィードバックが必要。

🗣️「このネジを締めて」 › 🦾 工具を把持 › 👁️ ネジ頭 + 溝方向を認識 › 📐 嵌合アプローチ IK › 🔄 押付け + 回転 + ずれ補正ループ › ✅ トルク上昇で締め完了
技術的なポイント
▸ 工具把持：グリップ位置・角度をカメラで認識し、滑らずに保持できる把持計画を生成。作業中の工具ずれを電流で検知
▸ 溝嵌合：ドライバー先端をネジ溝に合わせるため、VLM で溝方向を認識し初期位置合わせ。接触後は微振動 + 押付けで溝を探索
▸ 締め完了判定：関節トルクの急上昇でネジ着底を判定し、過締めを防ぐ（力制御モード）
