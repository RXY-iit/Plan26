📂 USD モデル構造
USD ファイル構成 ― overlay アーキテクチャ

稼働中の USD は以下の 2 層構造になっています：

robot_sim_physics.usd ← 現在実行するファイル（overlay）
└─ references ──▶ robot_sim_flattened.usda ← 全メッシュ・関節が含まれた基底 USD

robot_sim_physics.usd はロボットのメッシュを再生成せず、 既存の flattened USD の上に 物理設定・ROS2 ブリッジ・地面・センサーマウント を重ねます。 変更が最小限で済み、メッシュ更新と物理設定を分離できます。

⚙ 物理定義
Physics Articulation Root — base_footprint

/World/robot_sim/base_footprint に PhysicsArticulationRootAPI を付与。Isaac Sim がここを関節ツリーの制御ルートとして認識します。質量・重心・慣性テンソルもここで上書きし、Play 後に安定して着地します。

Physics 底盤コライダーの設計意図

sim_chassis_collision はホイールの接地点よりも少し高い位置に設定されています。底盤が先にグラウンドと衝突すると前傾が生じるため、コライダーを浮かせることで ホイールのみが接地 するよう制御しています。

📐 三輪逆運動学 — cmd_vel → 6DOF
Math 速度指令から各ホイール目標値への変換ステップ

/sim/cmd_vel（geometry_msgs/Twist）の意味：

linear.x — ロボット前方速度 [m/s] linear.y — ロボット左方速度 [m/s] angular.z — Z 軸回転角速度 [rad/s]

変換手順：

① 各ホイールの接地速度を計算
   wheel_i_vx = vx − ω·y_i
   wheel_i_vy = vy + ω·x_i

② 転向角・速度へ変換
   steer_φ_i = atan2(vy_i, vx_i)
   drive_v_i = √(vx_i² + vy_i²)

③ 大回り防止（角度折り返し）
   |φ| > 0.71π → φ ±= π、v *= −1

④ 線速度 → 角速度
   rad/s = v / r   （r = 0.1125 m）

重要：/sim/target_joint_states では NaN を使い分け します。IsaacArticulationController は非 NaN 値のみ指令として扱います。

関節positionvelocity
wheel_*_steer（転向）転向角 φ_iNaN
wheel_*_drive（駆動）NaN角速度 [rad/s]

📅 2026-06-15 追加進捗 — カメラ・アームホルダー統合
USD robot_sim_physics.usd — 追加 Prim 構造

base_footprint 配下に以下の関節・リンクを追加しました。カメラホルダーとアームベース（リフト）は独立した関節として実装されています。

base_footprint (ArticulationRoot)
├─ lift_joint PhysicsPrismaticJoint Z軸 0.0 – 0.3 m (アームベース底座)
│ └─ lift_link RigidBody 1.5 kg
├─ camera_pan_joint PhysicsRevoluteJoint Z軸 ±90°
│ └─ camera_pan_link
│ └─ camera_swing_joint PhysicsRevoluteJoint Y軸 ±45°
│ └─ camera_swing_link
│ └─ d455_sensor (rsd455.usd — camera publisher ターゲット)

旧 camera_bottom_screw_frame/camera_link は TF 参照フレームとして残存。D455 sensor の実体は camera_swing_link/d455_sensor に移行。

Node sim_lift_command_node.py — 実機・仮想共用ブリッジ

アーム・カメラ制御を仮想環境で動かすための新規 ROS2 ノードを追加しました。実機側のジョイ入力ノードはそのまま共用できます。
