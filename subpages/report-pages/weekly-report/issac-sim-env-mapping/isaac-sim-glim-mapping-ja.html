  • unset RMW_IMPLEMENTATION CYCLONEDDS_URI を先行実行
  • quickstart が必要トピックと TF 出現を確認してから rosbag / GLIM を起動
  • bag 保存後は ros2 bag info で自動検証
  • ルール： Play 前に /point_cloud の publisher count が必ず 1 であることを確認

6
Isaac Sim フリーズ・CUDA error 700
RTX LiDAR 実行中にレンダリングが停止しクラッシュ
▼
⚠ エラーチェーン
isaacsim.sensors.rtx.plugin: CUDA error 700 OgnROS2PublishPointCloud.cpp: cudaErrorIllegalAddress Failed to wait on external semaphore Rendering failed
🔎 排査過程
  • 外部 articulation・D455・重複 publisher・旧 RenderProduct を削除しても一部改善のみ
  • シンプルなシーンと built-in os1_32 でも CUDA 700 が再現 → シーンやプロファイルが単独原因ではない
  • NVIDIA 公式 Isaac Sim 5.0.0 をクリーンインストール → 旧発行方式では依然 CUDA 700 が発生
  • ログに DispatchSync / WriterSyncGate 異常と illegal-cycle が crash 前に出現することを確認

結論：直接 Replicator writer / partial-scan パスが最も明確なトリガーリスク。底層の Isaac RTX バグが完全解消されたとは証明できていない。

✅ 解決（有効な回避策）
  • LiDAR 発行を ROS2RtxLidarHelper + fullScan=True + 1x1 render product に変更
  • LiDAR setup は各セッションで 1 回のみ実行
  • CUDA 700 発生後は Isaac を必ず完全再起動
  • Isaac 実行中は UI ウィンドウのドッキング操作を禁止
⚠️ 現状は「有効な回避策」です。少量の SDGPipeline illegal-cycle 警告は引き続き観察が必要です。
7
D455 内部 IMU の停止順序問題 NEW
D455 を camera-only に変換する際に (2,6) エラーが再発する
▼
⚠ 問題

D455/RSD455 を既存フローに組み込もうとすると (2,6) エラーが再発、またはネストされた rigid body エラーが発生する。

RSD455 missing rigid body nested rigid-body / xformstack error

特定のフロー：

  • RigidBody/Mass API を先に削除すると、内部 RSD455/Imu_Sensor が親の rigid body 削除後も tensor reader として登録されたままになり (2,6) を直接引き起こす
  • D455 を完全無効化（マッピングから除外）するだけでは、後で D455 を加えようとするたびに同様の問題が再現する
🔎 排査過程
  • D455 camera-only フローを 3 パターンで A/B テスト：
    ①RigidBody のみ無効化 → (2,6) 再現
    ②RigidBody/Mass API を先に削除 → (2,6) 再現
    ③内部 IMU を先に停用 → RigidBody/Mass API を削除 → エラー消滅
  • LiDAR-only 基線で安定動作を確認した後、D455 追加で差分を特定
✅ 解決 — prepare_d455_camera_only.py

必ず以下の順序で実行します：

  1. D455 内部 RSD455/Imu_Sensor を先に停用
  2. その後で RSD455 の RigidBody / Mass API を削除
  3. 碰撞と joint を無効化
  4. Camera prim のみ保留（ROS 画像記録に使用）
順序を逆にすると、内部 IMU が親 rigid body の削除後も tensor reader として残り、(2,6) を直接引き起こします。

D455 ROS setup は Play 後、LiDAR setup の実行後に 1 回だけ実行します：

exec(open(".../prepare_d455_camera_only.py").read())   # Play 前
# Press Play
exec(open(".../setup_isaac_mid360_like_ros.py").read()) # Play 後
exec(open(".../setup_isaac_d455_ros.py").read())        # Play 後（LiDAR の後）

最新 D455 デフォルトセッション（trueimu_d455_002）では (2,6)・nested rigid body・RSD455 missing rigid body のいずれも再現せず。

今週の学び
  • 最小 LiDAR-only 基線を先に確立し、D455 等の旁路センサーを 1 つずつ追加して検証する
  • D455 のような複合センサーは内部コンポーネント（IMU・RigidBody）の停用順序が重要。順序の誤りが予期しないエラーを引き起こす
