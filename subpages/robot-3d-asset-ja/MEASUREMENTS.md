# 現在の実機寸法基準

最終更新：2026-09-20

Blender モデリング時に最初に参照する寸法資料。詳細な根拠スナップショットは `references/hardware-docs/robot_frame_dimensions.md`、機械可読版は `data/physical-measurements.json` を参照。

## 確認済み

| 項目 | 現在値 | 根拠の状態 |
|---|---:|---|
| 底部 frame の前後長 X | `700 mm` | 実機の水平測定、オレンジの注記 |
| 底部 frame の左右幅 Y | `600 mm` | 実機の水平測定、オレンジの注記 |
| 構造上面の高さ | `300 mm` | 地面から上面まで、青の注記 |
| 構造上面の高さ | `515 mm` | 地面から上面まで、青の注記 |
| 構造上面の高さ | `620 mm` | 地面から上面まで、青の注記 |
| 前方垂直ブラケット最上部の上面 | `1330 mm` | 地面から上面まで、青の注記 |
| 主車体/水平 frame の部材 | `4040` | `40 × 40 mm` |
| 前方 Arm/Camera/LiDAR 垂直ブラケット | `2020` | `20 × 20 mm` |
| Lift 機械ストローク | `200 mm` | 型式仕様と ABZO 端点の両方で確認 |
| Lift の通常ソフトウェア範囲 | `15–185 mm` | 現在の運用保護範囲 |

## Blender での直接利用

- 地面上の水平外形を `700 × 600 mm` で作成する。
- Z=`300 / 515 / 620 / 1330 mm` に 4 つの測定補助平面を作成する。
- 水平フレームにはまず 4040 断面を使い、前方の Arm/Camera/LiDAR 垂直ブラケットには 2020 断面を使う。
- Lift prismatic のストロークには `0–200 mm` を使い、旧 `230 mm` は使わない。
- `arm/base_link` の既存の下端地上高 `1005 mm` を採用する場合、Lift 上端の地上高は `1205 mm` となる。

## 既存資料から導出できるブロックモデル座標

以下は新たな実機測定値ではなく、実測外形 `700 × 600 mm` と既存の運用座標を組み合わせた結果である。Blender L0 に使用でき、代用オブジェクトには `DERIVED_RUNTIME` と表示する。

### base_link に対する車体外形

既存モデルでは車体の幾何中心を `base_link X=-90 mm`、Y=`0` に置く。実測値 X=`700 mm`、Y=`600 mm` と組み合わせると次のようになる。

| 境界 | base_link 座標 |
|---|---:|
| 前端 | X=`+260 mm` |
| 後端 | X=`-440 mm` |
| 左端 | Y=`+300 mm` |
| 右端 | Y=`-300 mm` |

現状で最も整合する暫定組立基準であるが、幾何中心のオフセット `-90 mm` は運用モデル由来であり、今回の実測値ではない。

### 外形に対する 3 輪の位置

| 車輪 | 軸中心 XY（base_link） | 導出できる端からの余裕 |
|---|---:|---:|
| 左前 | `(+206.4, +248.9) mm` | 前端から内側 `53.6 mm`、左端から内側 `51.1 mm` |
| 右前 | `(+206.4, -248.9) mm` | 前端から内側 `53.6 mm`、右端から内側 `51.1 mm` |
| 後輪 | `(-385.0, 0) mm` | 後端から内側 `55.0 mm`、左右中央 |

車輪半径は `112.5 mm`、URDF の代用幅は `60 mm`。タイヤとブラケットの実際の外形は未記入。

### 現在の運用センサ/機構の基準点

| 基準点 | base_link XYZ | 地上高 Z | 状態 |
|---|---:|---:|---|
| MID360 取り付け底面の原点 | `(+240, 0, +1380) mm` | `1492.5 mm` | 現在の URDF runtime。物理値は未確定 |
| D435 Pan 軸 | `(+275.347, -0.439, +622.5) mm` | `735.0 mm` | 現在の校正済み URDF |
| D435 Tilt 軸、neutral | `(+300.347, -0.439, +657.5) mm` | `770.0 mm` | 現在の URDF transform の合成値 |
| D435 holder、neutral | `(+318.242, +0.446, +631.149) mm` | `743.649 mm` | 現在の URDF transform の合成値 |
| SO101 base、Lift 下端 | `(+320.84, +12.62, +892.5) mm` | `1005 mm` | 現在の mount runtime/校正値 |
| SO101 base、Lift 上端 | `(+320.84, +12.62, +1092.5) mm` | `1205 mm` | 下端に確認済みストローク 200 mm を加算 |

MID360 は旧コメントと実際の運用 property が食い違うため、初版では runtime 値で配置し、`UNVERIFIED_PHYSICAL` と表示できる。D435 の 3 値から現在の neutral 視点を再現できるが、ブラケット CAD を表すものではない。

## 未記入のまま保持する項目

図の `300 / 515 / 620 mm` は確認済み。次の意味付けは未記入とする。

1. 各高さがどの 4040 frame 層に対応するか。
2. 各層の前後/左右の範囲。
3. 各層に取り付ける部品。
4. 4040/2020 の個々の切断長と接続関係。
5. MID360 の物理的な取り付け transform と Pan/Tilt ブラケット形状。
6. タイヤ、ホイール、操舵/走行ブラケット、取り付け板の外形。

データ ID は `frame_top_h300`、`frame_top_h515`、`frame_top_h620` に固定する。該当フィールドは JSON 内で `null` を保持し、斜視写真から推測しない。

## これらの寸法からは導出できない事項

- footprint 内での `base_link` の実測 X/Y。上記の境界はモデルからの導出値にすぎない。
- MID360、D435、Lift 基準点の独立した再測定。上記座標は runtime/校正の基準値である。
- 1330 mm のブラケット平面から MID360 frame/本体最高点までのオフセット。
- 各 4040/2020 部材の切断長、接続方法、数量。
- ロボットの最大高さ。Arm の姿勢や LiDAR 本体が構造上面より高くなる可能性がある。
