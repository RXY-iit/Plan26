# Robot Atlas · v003 実装説明

更新日：2026-09-20。

## 起動とファイル

`启动预览.command` をダブルクリックするか、`python3 serve.py` を実行します。本機のサーバー経由でブラウザーの `web/` を開きます。編集可能なマスターファイルは `blender/robot_master_v003.blend` です。v001 / v002 と元の `references/` スナップショットを保存しています。Web の全スクリプトと表示メッシュを同梱し、CDN には依存しません。

## 今回の修正

- 構造用金属は淡い青の金属外観、SO101 本体は淡い青、プリント製ブラケットは黄色としました。市販機器は製品本来の外観を保持しています。
- 3台の Drive の長軸を鉛直方向に配置し、出力軸を車軸に合わせました。後輪 ID1、左前 ID2、右前 ID3 にそれぞれ対応する銘板写真を紐付け、後輪写真の共用を解消しました。
- 3台の BLVD-KRD は個別に選択でき、車輪ユニットに分類しています。高さ300 mmの棚で、ID1/2は左側（+Y）、ID3は右側（−Y）です。
- AZD-KD、Arduino、MOSFET 5 V→24 V、RS-485 は黄色のプリント製トレーを共用します。分解図でも一つのアセンブリとしてまとまりを保ちます。
- MID360 の視野はセンサーのローカル中心平面を基準に、下7°、上52°、水平360°とし、取付姿勢に追従します。表示半径は模式図用で、測距範囲ではありません。
- D435 は測定図の前方0.4–1.6 m、手前側の幅0.7 mを採用しました。取付俯角は参考高さと両端から推定し、奥側の幅は概念上の延長です。元の運用 URDF/TF は変更していません。地面境界は組立状態で表示します。
- 正式な Evidence には、確認可能な製品出典、ハードウェア文書、実機写真のみを掲載します。運用記録と概念図は Reference に分け、設計説明には外部根拠がない場合も許容します。フィードバックと開発用手描き図は開発記録に移し、ページには表示しません。

## モデルと検証の範囲

選択可能な部品は37個です。Lift の機械ストロークは0–200 mm、通常のソフトウェア動作範囲は15–185 mmです。SO101 ベースのモデル上の端点地上高は1005/1205 mmです。アームの0.9–1.7 mは対象物の高さの設計範囲であり、検証済みの到達範囲ではありません。

MID360、XH540、XC330 は公式STEP、SO101 と D435 は元のメッシュを使用しています。Lift と Drive は公式寸法図から再構成しています。ブラケットの穴位置・厚さと正確な取付位置は再測定が必要です。XH540 はSTEP形状検査に合格しています。XC330 は開いたシェル6件、MID360 は開いたシェル・自己交差1件を含みます。メーカーの元の形状を保持し、閉じた加工用ソリッドとしての適合を表明するものではありません。詳細は `references-v2/products/sources.md` と `references-v2/cad/validation/` にあります。

`node web/validate-assets.mjs` は、2段階のGLBの部品、座標、階層に沿った分解・復元、六軸の参考姿勢、Lift端点、材質、車輪駆動部の鉛直方向、制御基板の左右配置、トレーの組立、根拠ファイルのパス、リソースハッシュを検査します。レポートは `data/validation-report.json`、元の参考スナップショットの整合性記録は `data/reference-integrity.json` にあります。

実機動作、負荷、干渉、認識範囲の実測は検証に含みません。CADビューアーは追加の本機プロセスです。同梱の静的検査画像は、このプロセスなしでも閲覧できます。

## 再生成

`blender/scripts/prepare_v003.py` はv002データアーカイブから現在の資料を準備します。`blender/scripts/build_robot.py` はBlenderシーン、2段階のGLB、レンダリング画像を生成します。

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python blender/scripts/build_robot.py
node web/validate-assets.mjs
```

メーカーSTEPの変換環境 `.cad-venv` はポータブル版に含めません。Blenderでの再生成に必要なSTLは `blender/derived/` に同梱しています。
