最終更新：2026-09-20

目的：実機から直接測定した機体の構造寸法を記録します。ここでの `frame` はアルミフレーム構造を指し、ROS TF frame ではありません。

## 1. 今回の測定の出典

- 元写真：`hardware/real-bot-figure/IMG_0179.jpg`
- 測定方法：操作者が実機を測定し、その寸法を写真に記入
- 色の定義：オレンジは地面に平行な水平寸法。青は地面から該当するアルミ frame 上面までの鉛直距離
- 注記画像の原本は現時点で 2026-09-20 の会話添付にのみ存在し、作業フォルダーには未保存。以下の表は、持ち運び可能な寸法のテキスト記録

## 3. アルミフレーム材の仕様

| 部位 | 部材断面 | 現在の記録 |
|---|---:|---|
| 主車体と図中の各水平 frame | `40 × 40 mm` | 4040 アルミフレーム材 |
| 前方の Arm/Camera/LiDAR 垂直支持部 | `20 × 20 mm` | 2020 アルミフレーム材 |

各部材の切断長、数量、溝のシリーズ、コーナーブラケット、端部の接続方法は未記録です。`700 × 600 mm` は水平外形の測定値であり、各部材の切断長にそのまま分解することはできません。

## 4. 現在の Lift の機械的事実

| 項目 | 現在の値 |
|---|---:|
| アクチュエーター | `EASM2XF020AZAK` |
| 機械ストローク | `200 mm` |
| 通常のソフトウェア動作範囲 | `15–185 mm` |
| 旧 Arm 表示 span | `230 mm`。不正確と確認し、廃止済み |

既存の Lift 下端での `arm/base_link` 地上高 `1005 mm` の測定値を維持した場合：

- Lift 下端：`arm/base_link` の地上高は `1005 mm`、`base_link` に対する Z=`892.5 mm`。
- Lift 上端：地上高は `1205 mm`、`base_link` に対する Z=`1092.5 mm`。
- この換算は Arm の取付 frame の Z のみを表し、SO101 全体の最高点ではありません。

## 6. 最低限必要な追加確認

1. `300 / 515 / 620 mm` の各上面に、「下部主 frame」「前部コンソール frame」「中央上段 frame」などの構造名を付ける。
2. `1330 mm` は 2020 支柱・横梁の上面であり、MID360 の取付底面や最高点ではないことを確認する。
3. `700 × 600 mm` の footprint 内での `base_link` の X/Y 位置を測定し、外形を ROS 座標に配置できるようにする。
4. MID360 取付底面中心、D435 Pan 軸心、Lift レール・スライダー基準面から footprint の三辺までの水平距離を測定する。

## 7. モデル作成時の使用ルール

- Blender の初版は X=`700 mm`、Y=`600 mm` で車体の水平外形を作成できます。
- Z 方向には `300 / 515 / 620 / 1330 mm` の4つの補助平面を使用します。
- 4040 と 2020 は実際の断面寸法でモデル化します。各部材の長さは、追加測定前に透視写真から精密な値として逆算してはいけません。
- センサーと Arm の原点には URDF/キャリブレーションデータを暫定使用しますが、構造上面の実測とは独立した情報であることを明示します。
