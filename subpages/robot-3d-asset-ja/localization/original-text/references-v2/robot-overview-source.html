昇降機構（Arduino / MOSFET / AZD-KD）
完了: 2026-05-10
✅ 完了
機械臂底座の昇降機構を 3D プリント製ホールダーに搭載。Arduino → MOSFET → AZD-KD の制御システムを実装し、ROS2 からの UP / DOWN / STOP / HOME コマンドで制御可能。JOG 速度 60 mm/s 達成（目標値 50 mm/s 超え）。自動ホーミング機能も実装済み。
