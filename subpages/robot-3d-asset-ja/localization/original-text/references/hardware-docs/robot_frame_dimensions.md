# Robot frame 实机尺寸记录

最后更新：2026-09-20

用途：记录从实机直接测量得到的整机结构尺寸。这里的 `frame` 指铝型材结构，不是 ROS TF frame。

## 1. 本轮测量来源

- 基础照片：`hardware/real-bot-figure/IMG_0179.jpg`
- 测量方式：操作者在实机上测量后，将尺寸标注到该照片
- 颜色约定：橙色为平行地面的水平尺寸；蓝色为地面到对应铝型材 frame 上平面的垂直距离
- 标注图原文件目前只存在于 2026-09-20 对话附件，尚未落入工作区；以下表格是尺寸的可移植文字记录

## 4. Lift 当前机械事实

| 项目 | 当前值 |
|---|---:|
| 执行器 | `EASM2XF020AZAK` |
| 机械行程 | `200 mm` |
| 日常软件区间 | `15–185 mm` |
| 旧 Arm 可视化 span | `230 mm`，已确认不准确并停用 |

在保留既有 Lift 下端 `arm/base_link` 离地 `1005 mm` 测量的前提下：

- Lift 下端：`arm/base_link` 离地 `1005 mm`，即相对 `base_link` Z=`892.5 mm`；
- Lift 上端：离地 `1205 mm`，即相对 `base_link` Z=`1092.5 mm`；
- 该换算只描述 Arm 安装 frame 的 Z，不代表 SO101 整体最高点。

## 6. 仍需最小确认

1. 分别给 `300 / 515 / 620 mm` 三个上平面指定结构名称，例如“底部主 frame”“前部控制台 frame”“中央上层 frame”。
2. 确认 `1330 mm` 是 2020 立柱/横梁的上表面，不是 MID360 的安装底面或最高点。
3. 测量 `base_link` 在 `700 × 600 mm` footprint 内的 X/Y 位置，才能把外形放入 ROS 坐标。
4. 测量 MID360 安装底面中心、D435 Pan 轴心、Lift 导轨/滑块基准面相对 footprint 三条边的水平距离。

## 7. 建模使用规则

- Blender 第一版可使用 X=`700 mm`、Y=`600 mm` 建立底盘水平包络。
- Z 方向使用四个辅助平面：`300 / 515 / 620 / 1330 mm`。
- 4040 与 2020 使用真实截面尺寸建模；每根长度在补测前不得从透视照片精确反推。
- 传感器和 Arm 原点使用 URDF/标定数据作为临时值，但必须标记为独立于结构上平面测量。
