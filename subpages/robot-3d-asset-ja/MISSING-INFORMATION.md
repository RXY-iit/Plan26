## 一時的に補完を保留する空白フィールド

これらの内容は、オペレーターによる回答を一時的に要件としていません。また、Blender L0 をブロックすることもありません。既存の座標は、
`MEASUREMENTS.md` の `DERIVED_RUNTIME` 値に基づいてダミーモデルを構築できます。以下のフィールドは空欄のままにしておき、
後で直接測定または CAD が行われた場合に補完します。

1. `300 / 515 / 620 mm` の３つの上平面にそれぞれ名前を付け、それぞれがカバーする 4040 frame を示します。
2. `1330 mm` が 2020 ブラケットの最上部構造平面であり、LiDAR 取付底面や LiDAR 頂上ではないことを確認します。
3. `base_link`/車軸基準を `700 × 600 mm` footprint 内で前縁、左側の水平距離を測定します。
4. MID360 取付底面中心が footprint に対しての X/Y/Z と実際の傾斜角を測定します。
5. D435 Pan 軸心、Tilt 軸心とカメラ取付面の X/Y/Z を測定します。Pan/Tilt モーター型番を提供します。
6. Lift ガイドレール中心線、下端スライダー取付面と SO101 base に対して footprint の X/Y を測定します。Z 下端には既に `1005 mm` 地上高の記録があります。
7. 各 4040/2020 の切断長さ、数量と接続関係を提供するか、六面直交写真に巻尺を加えたものを補完撮影します。
8. 車輪ユニット外形/ブラケット寸法、および車軸が footprint に対しての位置を提供します。現在、kinematics の相対座標のみがあります。
9. 取付板、Lift/Arm 转接件と Pan/Tilt プリント部品の STL/STEP/寸法を提供します。

後で元のエビデンスを整理する場合、本ラウンドのオレンジ/ブルー寸法注釈付きのオリジナル図を
`references/photos/measurements/IMG_0179_measurements_20260920.png` として保存できます。現在の作業領域は会話中の表示図にしかアクセスできず、元の添付ファイルバイナリを取得できません。

## P0：開始可能な信憑性のある全体機モデリング材を補完する前に必須

### A. 座標基準と全体機体外形

- [ ] 本会話の組立図/分解図のオリジナル図を `references/concept/` に保存し、画像のソースまたは使用許諾を記録します。

- [ ] 前、後、左、右、頂、底の六面直交写真を撮影します。各写真には同じ平面のスケールを配置します。
- [ ] 30–45° の等高リング周囲写真を撮影し、遮蔽構造と材質を確認するために使用します。
- [ ] ロボットの「前方」と３つの名前、ROS wheel ID の対応関係を明確にします。
- [ ] 写真撮影時の Lift、Pan、Tilt と Arm 六関節位置を記録します。

### B. 既存の寸法干渉を解消する

- [x] 底部 frame の水平外形：2026-09-20 実測 X=`700 mm`、Y=`600 mm`。旧 `670 mm` の URDF box は実寸として使用しない。
- [ ] 構造上面の実測値は `300 / 515 / 620 / 1330 mm`。下側 3 平面の正確な構造名を対応付ける必要があり、機体最大高さは別途測定する。

- [ ] MID360 の `30°` pitch が実際の取り付け角、運用補正角、旧値のいずれかを確認する。

### L. Lift 選定と取付高さ

- [ ] SO101 必要な垂直動作範囲とターゲット物の典型的な高さ。
