# 日本語版について

`プレビューを起動.command` をダブルクリックすると、このフォルダーだけでプレビューを起動できます。Python 3 と WebGL 対応ブラウザを使用します。別のプレビューが既定ポートを使用中の場合は、空いている次のポートを自動で選びます。

UI、構造概要、設計・技術説明、Reference / Evidence、本体に同梱する閲覧用文書を日本語化しました。旧バージョンのアーカイブ、開発用フィードバック、実行コードと設定ファイル、メーカーから取得した原本データは追跡用に保持しています。画像内の文字と 3D モデルは元データのままです。

部品 ID、型式、数値、パス、リンク、画像、3D 形状、操作ロジックは原版と共通です。元のリンク先が別サービスを必要とする場合、その条件も原版と同じです。追加の CAD ビューアが停止していても、同梱の形状、画像、検査スナップショットは利用できます。

翻訳前の本文は `localization/original-text/`、ファイル別の対応とハッシュは `localization/ja-manifest.json`、言語以外の一致検証は `localization/verification.json` に保存しています。ライセンスの日本語文は閲覧用の参考訳で、英文原本も保持しています。
