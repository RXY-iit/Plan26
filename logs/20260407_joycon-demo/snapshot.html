Joy-Con からモーター制御までの流れ

全体フロー: /joy -> /cmd_vel -> /drive_vel + /steer_angle -> /set_position

このページは、今回のスナップショットに含まれるノード接続とパラメータを日本語で要約したものです。

STEP 1 Joy 入力

/joy_node が /joy (sensor_msgs/msg/Joy) を publish。

axes:    [0.0, 0.8, 0.0, -0.5, ...]
buttons: [0, 0, 0, 0, 1, 0, ...]
STEP 2 Twist 変換

/teleop_twist_joy_node が /joy を受けて /cmd_vel (geometry_msgs/msg/Twist) を publish。

linear.x  = axes[1] * 0.4
angular.z = axes[3] * 0.4

# turbo button(5) を押す場合
linear.x  = axes[1] * 1.0
angular.z = axes[3] * 0.6
STEP 3 モーター用指令へ分解

/cmd_vel_to_motor_node が /cmd_vel を受けて次を publish:

  • /drive_vel (my_messages/msg/DriveMotor)
  • /steer_angle (my_messages/msg/SteerMotor)
STEP 4 サーボへ書き込み

/steer_motor_node は /steer_angle を subscribe し、/set_position を publish。

/read_write_node が /set_position を受け取り、実機モーターへ反映。

NOTE 今回のスナップショットで見えた点
  • /cmd_vel_to_motor_node が 2 回表示されているため、同名ノード重複起動または採取時重複の可能性があります。
  • このレポートはトポロジとパラメータ中心で、各トピックのリアルタイム payload ログは含みません。
