モータテストガイド

0) 必要な準備

ワークスペースをセットアップしてから、シリアルノードを起動する必要があります：

初期セットアップ 
cd /home/matsunaga-h/pickup_ws
source install/setup.bash
node起動 
ros2 run serial_transciever angle_serial_node
ros2 run serial_transciever chokudo_cameraswing_air_serial_node
or launch起動 
ros2 launch launch/motor_launch.py

その後、以下のシリアルノードを起動します：

  • angle_serial_node.py（必須）
  • chokudo_cameraswing_air_serial_node.py
  • motor_manual_chokudo_node.py

または、両方をまとめて起動しても構いません。必要なシリアルノードを含む launch ファイルを使って一括起動してください。

1) キーボード入力でテスト

マニュアルノードを起動してからキーボード入力でテストできます。

マニュアルノード起動 
ros2 run motor_manual_chokudo_node motor_manual_chokudo_node

モータコマンド：

コマンド動作
A1 / B1モータ1の±90度回転
A2 / B2モータ2の±90度回転
A3～A9 / B3～B9モータ3～9の±90度回転
3 180モータ3を絶対180度に設定
CA / CBリニアモータ大移動（±4000オフセット）
D+ / D-カメラスイングステップ移動
A / K定義済み9モータポーズ

別のターミナルでフィードバック確認：

ターミナルコマンド 
ros2 topic echo /motor_current_angles
ターミナルコマンド 
ros2 topic echo /chokudomotor/angle
ターミナルコマンド 
ros2 topic echo /cameraswingmotor/angle

2) トピック直接パブリッシュテスト

2-1) 9モータ（モータ1～9）

/motor_anglesは毎回9つの値が必要です。

例：モータ1を300度に移動（他は現在値を保持）：

パブリッシュコマンド 
ros2 topic pub --once /motor_angles std_msgs/msg/Float32MultiArray \
"{data: [300.0, 265.0, 190.0, 91.0, 16.0, 15.0, 70.0, 87.0, 36.0]}"

2-2) リニアモータ（チョクド）

パブリッシュコマンド 
ros2 topic pub --once /chokudomotor/target_angle std_msgs/msg/Float32 "{data: 100.0}"

2-3) カメラスイングモータ

パブリッシュコマンド 
ros2 topic pub --once /cameraswingmotor/target_angle std_msgs/msg/Float32 "{data: 45.0}"

3) 推奨される完全なテストシーケンス

  1. ステップ1：全シリアルノードを起動
  2. ステップ2：キーボード入力テストで基本動作確認
  3. ステップ3：マニュアル操作で各モータを個別テスト
  4. ステップ4：トピックパブリッシュで複合動作テスト
  5. ステップ5：全モータを同時に目標位置に移動するテスト
