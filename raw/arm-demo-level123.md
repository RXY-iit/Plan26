## 🦾 カテゴリ B — アーム単体 Demo

*マニピュレーターの操作能力を、実世界で望まれるユースケースに結びつけながら段階的に実証する*


### このカテゴリで示したいこと

本カテゴリでは、単なる「アームが動く」ことではなく、
**人が自然に指示した作業を、環境改造なし・専用治具なしでロボットが実行できること**を示す。

従来の自動化は、設備改造・位置固定・事前調整を前提とすることが多く、
少量多品種・変化の多い現場では導入コストが高い。
そこで本デモでは、LLM・視覚認識・動作計画を組み合わせることで、
**人手作業の一部を柔軟に代替できる Physical AI 的マニピュレーション**を段階的に検証する。

---

# B-Level 1 — 音声指令による単発操作実行

### 例：エレベーターボタン押下 / 設備のスタートボタン押下 / スイッチ操作

* **Status:** planned
* **Phase:** 1–2

### 望ましいこと（Why）

研究室・工場・施設内には、
「ボタンを押す」「スイッチを入れる」といった**単純だが人手依存の操作**が多く残っている。
これらは作業としては簡単に見える一方で、既存設備とシステム連携しようとすると改修コストが高く、
従来の自動化では見合わないことが多い。

つまり、
**“人がその場で行っている簡単な物理操作を、設備改造なしで代替したい”**
というニーズがある。

### このLevelで実証すること（What）

「3階のボタンを押して」のような自然言語指示を受け、
対象を視覚的に認識し、位置を推定し、アームで正確に押下する。
これにより、**言語理解 → 対象認識 → 物理操作** の最小パイプラインを実証する。

### 解決したい痛点

* 設備側を改造しないと自動化できない
* 座標固定のスクリプトでは環境変化に弱い
* 人の指示をそのままロボット動作に変換できない

### このデモの価値

このLevelの価値は、
**「環境改造なしの低コスト自動化」** の可能性を示すことにある。

ボタン押下自体が重要なのではなく、
**人の言葉で指示された単発作業を、視覚を使ってその場で実行できる**ことが重要である。

### 説明

「3階のボタンを押して」という音声指示を LLM が解釈し、カメラでボタンを認識して SOARM101 で正確に押下する。単なる固定動作ではなく、対象認識を伴う物理操作の最初の実用デモとする。

### フロー

🗣️ 音声指示 → 🤖 LLM 解釈（対象・属性抽出） → 📸 カメラ入力 → 👁️ ボタン検出（YOLO/VLM） → 📐 Depth推定 + IK計算 → 🦾 SOARM101 押下 → ✅ 動作確認

### 技術タグ

SOARM101 / YOLO / VLM / IK / Depth estimation / LLM / Whisper

### Radar-scores

[1, 0, 3, 7, 5]

# B-Level 2 — 指示に基づく多段タスク実行

### 例：文字ブロックのスペリング / 物品の並べ替え / 指定順序での配置

* **Status:** planned
* **Phase:** 3–4

### 望ましいこと（Why）

実際の現場やサービス用途では、
ロボットに求められるのは「1回動くこと」ではなく、
**目的に応じて複数ステップを継続実行すること**である。

たとえば、

* 指定された順に物を並べる
* 必要な部品を集めて配置する
* ラベルや文字に基づいて対象を選別する

といった作業は、人間にとっては単純でも、
ロボットにとっては**認識・記憶・順序計画・反復操作**が必要になる。

### このLevelで実証すること（What）

「CAT を並べて」「APPLE を作って」といった指示を受け、
対応する文字ブロックを認識し、順序を計画し、複数回の把持・配置を継続して行う。
これにより、**単発操作ではなく、目的に対して自律的に手順を展開する能力**を示す。

### 解決したい痛点

* 既存ロボットは固定シーケンスに依存しやすい
* 目標が変わるたびに人がプログラムし直す必要がある
* 複数ステップ作業を柔軟に扱えない

### このデモの価値

このLevelの価値は、
**「動作の自動化」ではなく「タスクの自動化」** に進む点にある。

つまり、
人が逐一「次はこれ、その次はこれ」と教えなくても、
**目標だけ与えればロボットが内部で手順を構成して実行できる**ことを示す。

### 説明

物品名や文字列の指示から対象ブロックを認識し、LLM が順序を計画し、複数回の把持・配置を通じて目的物を完成させる。認識・計画・継続実行を統合した中級マニピュレーションデモ。

### フロー

🗣️ 物品名・文字列指示 → 🤖 LLM 解釈（スペリング・配置計画） → 👁️ OCR+YOLO による対象認識 → 📋 順序計画 → 🦾 ブロック把持 × N回 → 📍 指定位置に配置 → ✅ 完成確認

### 技術タグ

YOLO / OCR / IK / FK / LLM Planner / Sequential manipulation / Depth estimation

### Radar-scores

[0, 2, 4, 9, 5]

# B-Level 3 — 視覚フィードバックを用いた精密操作

### 例：プラグ挿入 / コネクタ接続 / 穴合わせを伴う組付け

* **Status:** future
* **Phase:** 5–6

### 望ましいこと（Why）

現実の作業では、価値の高いマニピュレーションの多くが
**ミリ単位のズレで失敗する精密操作**である。

たとえば、

* プラグやUSBの挿入
* コネクタ接続
* 穴位置を合わせる組付け
* 接触を伴う精密作業

これらは単純な位置決めだけでは不十分で、
現場では誤差・たわみ・視点変化・個体差が常に存在する。
したがって、望まれているのは
**“一回で正確に動くロボット” ではなく、“ずれても自分で修正できるロボット”**
である。

### このLevelで実証すること（What）

対象を認識して初期位置合わせを行うだけでなく、
作業中の映像や接触状態を使ってリアルタイムに補正しながら挿入を完了する。
これにより、**open-loop な再生動作ではなく、閉ループで成功に到達する能力**を示す。

### 解決したい痛点

* 高精度な事前調整がないと作業が成立しない
* 少しの誤差で失敗する
* 環境変化に弱く、実運用で安定しない

### このデモの価値

このLevelの価値は、
**不確実環境でも成功まで持っていけるロボット操作**を示すことにある。

ここで重要なのは「プラグを挿せた」ことそのものではなく、
**認識・接触・補正を組み合わせて、失敗しやすい作業をやり切れること**である。
これは、実環境導入に向けた大きな一歩となる。

### 説明

コンセントやコネクタへの挿入のような精密作業を対象に、視覚認識に基づくアプローチ動作と、視覚・接触・電流値を用いた補正ループを組み合わせる。視覚と制御が密結合した高難度マニピュレーションの実証。

### フロー

🗣️ 操作指示 → 👁️ VLM/YOLO による挿入口認識 → 📐 初期IK計算 → 🦾 挿入アプローチ → 🔄 視覚/接触フィードバック補正ループ → ✅ 挿入確認（電流/映像）

### 技術タグ

SOARM101 / IK / VLM / Visual Feedback / Current sensing / Closed-loop control

### Radar-scores

[0, 1, 4, 10, 3]

# この3段階のつながり

このカテゴリは、単に難易度が上がる構成ではなく、
**「望ましいロボット能力」を段階的に実証するロードマップ**として位置付けられる。

* **Level 1:**
  人の自然言語指示を、単発の物理操作に落とし込める
  → **低コスト・非侵襲な自動化の入口**

* **Level 2:**
  単発動作ではなく、目標から複数手順を構成して実行できる
  → **タスク単位の自律化**

* **Level 3:**
  誤差や不確実性のある実環境でも、補正しながら作業を完遂できる
  → **実運用に耐えるロバスト操作**

# 一句话版总结

このカテゴリで示すのは、
**「アームが動くこと」ではなく、
人の指示を理解し、環境を認識し、必要な手順を構成し、不確実性の中でも物理作業をやり遂げる能力」**
である。
