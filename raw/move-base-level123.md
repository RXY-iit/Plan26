# 机器人导航系统 Level 1-3 分级标准

这份文档定义了基于 ROS2 + Mid360 的机器人从基础导航到任务自主的三个能力等级。

---

## 一句话总览

| Level | 本质 |
|-------|------|
| **L1** | **看当前 → 做反应**（Reactive Navigation） |
| **L2** | **看记忆 → 更好地走**（Memory-Enhanced Navigation） |
| **L3** | **会思考 → 主动解决**（Interactive Adaptive Autonomy） |

---

## ✅ Level 1：环境理解驱动的即时自主导航

**本质**：看当前 → 做反应（Reactive AI）

**能力**：
- 感知（LiDAR / Camera）
- 局部路径规划（避障）
- 简单目标导航（给一个点就去）

**典型场景**：
- 室内配送：用 LiDAR 定位 + 动态避障
- 工厂巡检：固定路线 + 遇障碍绕行
- 语音导航："去前面的门口" → 识别目标 → 规划执行

**关键组件**：Localization / Path Planning / Obstacle Avoidance / TF Tree

**你现在的进度**：👉 Mid360 + ROS2 + Nav2 就在这个 Level 1
- 需要完成：稳定里程计、完整 TF 树、小范围建图、基础避障

---

## ✅ Level 2：记忆增强的经验型自主导航

**本质**：不仅看现在，还利用过去（Memory AI）

**核心能力**：
- 地图 + 语义信息
- 经验记忆（哪条路快、哪里堵、哪里有门）
- 任务上下文记忆
- 失败恢复学习

**典型场景 - 办公室服务机器人**

任务：**"帮我把东西送到3L402"**

能记住：
- 3L402 在哪、哪个电梯更快、哪条走廊常堵
- 这个门通常是关的，需要绕路
- 上次开门失败（角度不对）→ 这次自动调整姿态

**记忆类型**：
- 空间记忆：哪里常堵、哪里有门
- 失败记忆：某条路线失败过，优先不再走
- 交互记忆：用户偏好和习惯
- 语义记忆：语义地图（这是厨房、这是人多区域）

**实现方式**：Memory / RAG / History / LLM 机制
- 记忆检索、历史总结、高层策略、面向人的解释

---

## ✅ Level 3：预测 / 协作 / 自我优化（任务级自主）

**本质**：像人一样做任务，而不是执行导航

**核心特征**：

#### 1. 会判断：继续尝试、切换策略，还是求助
- 识别异常：卡住、识别不准、连续规划失败、技能不适用  
- 决策：retry / replan / call tool / ask human

#### 2. 会主动调整身体和观察方式
- 抬头/低头重新看、向左/右挪动、后退重新观察
- 靠近目标再识别、调整姿态以便识别细节
- 感知从被动读取 → **主动探索**

#### 3. 会调用 task / skill / 外部能力
- 地图服务、数据库、知识库、API
- 内部 skill（开门、识别按钮、乘电梯）
- 记忆系统 + 更强的感知或推理模块

#### 4. 围绕任务目标持续推进
- 拆分任务阶段、判断前置步骤
- 失败时切换备用方案、根据优先级调整顺序
- 与人或其他系统协作

**完整场景：去 3L402 并完成任务**

**L1 表现**：
- 走到门前 → 发现路径不通 → 停住或简单重规划

**L2 表现**：  
- 记得门经常关闭 → 优先选另一条路线

**L3 表现**：
- 判断"门阻挡路径，状态不确定"
- 主动靠近、调整视角识别把手或门牌
- 调用工具判断：自动门 / 推门 / 拉门？
- 技能不足？向人求助 + 记录结果
- **继续推进原任务，不卡在门前**

**项目价值亮点**：
- 论文发表（自适应自主性）
- 展会 demo（人机交互）
- 商用落地（可靠性）

## 🔥 三个 Level 完整对比

| 维度 | Level 1 | Level 2 | Level 3 |
|------|---------|---------|---------|
| **本质** | 反应式 | 有经验 | 会思考 |
| **核心循环** | 感知 → 规划 → 控制 | + 记忆查询 | + 异常判断 + 求助 |
| **避障** | 简单躲避 | 避开高风险区 | 主动获取信息后避障 |
| **失败处理** | 停止或重规划 | 查询历史改策略 | 重试/改工具/求助 |
| **与人交互** | 无 | 可查询用户偏好 | 主动识别问题、求助 |
| **记忆使用** | 无 | 被动使用 | 主动构建和利用 |
| **适用场景** | 工厂/清洁/巡检 | 完整服务机器人 | 不确定环境+复杂任务 |

## 最终版本 - 速查表

### Level 1：基于当前感知的即时自主导航
- 从当前位置去 3L402
- 前方有人时暂停并绕行
- 通道被挡住时重规划

### Level 2：基于记忆与经验的自主导航
- 避开过去经常拥堵的走廊
- 记住用户偏好"优先坐电梯"
- 记住某扇门需要拉开而不是推开

### Level 3：基于交互、自适应与任务推进的自主行动
- 看不清门把手时主动靠近并换视角
- 连续失败后自动改用其他工具或技能
- 不确定按钮时向人确认
- 为完成主任务，先执行前置步骤再继续导航
